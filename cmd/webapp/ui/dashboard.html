本地出口代理

把你自己的电脑做成出口代理：本机 agent 跑一个本地代理， 再用 SSH 反向隧道把它接到云端 —— 于是你名下的代挂账号访问上游时 是从你家宽带出去（住宅 IP 比机房 IP 友好得多）。
只需在本机启动一次 agent（页面会给命令），之后在下面点一次就好； 无需手工填写任何地址、端口或绑定关系。
这条线路只作用于你自己的号：平台的全局默认出口不会被动， 也不会影响任何其他用户。管理员可在后台看到这条线路并显式分配给别的号。

添加代挂账号（扫码授权）

把你的 WorkBuddy 账号挂到平台：账号仍归你所有。按版本扫码添加（国内版 / 国际版登录态不通用）。 给账号设好分组后，在「API 密钥」页生成密钥时勾中它即可免费自用； 也可以申请进号池由平台反代、按分成比例把收益折成点数入你的余额（见「我的返点」）。

全部代挂账号 · 定时任务

这里统一开关全部代挂账号的自动任务；单个账号的差异在下方每张账号卡片里单独设置。 账号在池中自动签到 / 做任务维持额度，改动即时生效。

代挂收益

我的代挂账号 · 成长任务

官方「成长计划」有一批任务，做完能拿积分与能量。 成长任务不会自动跑（它会对账号发起真实请求），由你在这里勾选账号后手动执行： 后台逐个串行推进、账号之间随机等待数十秒到两分钟。
执行链路是「先跑不消耗额度的行为上报攒积分 → 再跑需真实对话的消耗类」； 已完成的由服务端自动跳过，重复跑不会重复扣资源。

号池返点

比例 —
你的代挂账号进入号池、被平台用来反代后，平台按「该次消耗的号池积分 × 分成比例」把收益折入你的余额。 本页金额一律以「钱」（¥）呈现，按提现折算比例换算；括号内的点数是余额里实际入账的单位。 分成基数取号池积分本身，不受平台计费倍率影响；单次以平台实收为上限。

推广返点

比例 —
把你的邀请码分享出去：下级兑换充值、以及下级的代挂账号在号池赚到收益时，你都能拿返点。

插件

可独立启停的功能扩展
插件是可安装 / 可停用的功能单元：每张卡片右侧有开关，停用只影响你自己 （入口与执行都停下，不会改动任何数据，随时可再启用）。 平台是否提供某个插件由管理员决定 —— 若显示「平台已停用」，请联系管理员。 点开卡片即可使用；批量类操作一律逐个串行出站，不做"一键全并发"。
